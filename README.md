# fhrodrigues.github.io

Personal academic website for **Fabrício Henrique Rodrigues**, built with Jekyll and hosted on GitHub Pages.

## Structure
- `_config.yml`: Site configuration, navigation, and profile metadata.
- `_data/publications.yml`: Structured publication list with BibTeX entries.
- `index.md`: Home page (Research Thesis, Bio, Selected Work).
- `research.md`: Core research pillars, projects, and technical stack.
- `publications.md`: Filterable bibliography with interactive BibTeX copy.
- `cv.md`: Academic trajectory, editorial service, event organization, and teaching.
- `assets/css/style.css`: Custom Editorial Contemporary stylesheet (Deep Forest Emerald palette + automatic dark mode).
